atelier GitHub

One harness. Every skill under /tfx:.

atelier bundles engineering and design skills into a single Claude Code plugin, so a team builds and reviews product work the same way every time.

Install

Add the marketplace, then install the plugin.

/plugin marketplace add transformteamsg/atelier /plugin install tfx@atelier

Then run any skill as /tfx:code-review, /tfx:design, and so on.

How it works

  1. One namespace. All 19 skills install together and run under a single /tfx: prefix.
  2. Standards, enforced. The design skills ship a control catalog and deterministic checks that run on every page.
  3. Generator and evaluator split. A separate evaluator agent grades design work, so the builder never marks its own homework.

Skills

Engineering (8)

code-review
Review a diff and post findings as inline PR comments or a local branch review.
create-issue
Draft a well-structured GitHub issue ready for a coding agent.
groom-issue
Fill in an issue's technical sections before build.
split-issue
Break a large issue into atomic, single-PR child issues.
implement-issue
Implement a groomed issue end to end and open a pull request.
lint-setup
Detect project types and set up linting and formatting.
git-hooks-setup
Set up or audit pre-commit and pre-push hooks.
update-npm-dependencies
Audit and update vulnerable JavaScript dependencies safely.

Design (11)

start
Orient and route to the right design skill.
setup
Install the per-user design tools and product context.
design
Run the full design loop from intent to verified UI.
critique
Grade an existing page and return ranked fixes.
standards
Read, apply, and grow the standards catalog.
copy
Write and review UI copy in the TFX voice.
layout
Tighten structure, hierarchy, and density.
polish
Refine a named visual dimension such as spacing or type.
motion
Smooth transitions, easing, and timing.
flow
Improve a multi-step task's path and states.
feedback
File harness feedback as a GitHub issue.
