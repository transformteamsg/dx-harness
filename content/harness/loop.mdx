The harness wraps an AI agent so that what it designs complies with this standard, not by asking nicely but by structure. Its central promise: **intent without loss.** What you mean is written as a contract in phase 1. Every later phase is graded against it, and drift is a defect. Every phase grades against the [control catalog](/standards/catalog).

## The two gates

The loop stops twice, and both stops are yours. The plan gate means nothing is built unseen: you read what the agent intends (components, content, error states, waivers). No code exists until you approve it. The verify gate means a waiver is a human decision. The checks and the evaluator report what failed, but only you can accept a deviation from the standard. Between the gates the agent moves fast, because the contract you approved already binds it. If a gate ever surprises you, the defect is upstream — in the intent or the plan, not the build.

## The outer loop

The ratchet learns from our failures; the **outer loop** learns from teachers' reality. It normalises feedback and telemetry into tagged evidence records, then surfaces one automatically when you touch a tagged pattern. These records accumulate until they close **open pattern questions** (e.g. OPQ-1: table density). While an OPQ is open, the harness treats competing hypotheses as valid divergence directions; it never enforces a guess as if it were a standard.
