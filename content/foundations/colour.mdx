## Product primaries

Each destination product gets its own primary. Teacher Workspace keeps its brand blue; CaseSync and Glow draw from **Radix Colors** scales, so states, tints, and dark-mode variants come for free. Posts and PG Staff Portal use TW's blue: they don't carry their own colour.

<PrimarySwatches />

What stays shared across all products: **neutrals** (Radix `gray`/`slate`), **functional colours** (success/warning/danger from Radix `grass`/`amber`/`red`, COL-2), typography, illustration style, and spacing. A product changes its accent, never its character.

## The Radix scales

Each Radix colour ships as a 12-step scale with defined roles: backgrounds, component states, borders, solid fills, and text. Picking from Radix means every product's hover, pressed, and disabled states are consistent by construction.

## Functional colours

Functional colours always come from the shared Radix scales — `grass` for success, `amber` for warning, `red` for danger — never picked ad hoc (COL-2).

<FunctionalColours />

The warning text token is darkened past Radix amber-11 on purpose: amber-11 caps at roughly 4.6:1 even on white, so it fails AA on the tinted warning background. The darkened value clears 6.1:1 instead.

## Semantic tokens

Tokens describe purpose, not appearance, so a colour can change without touching a single component.

## Usage

```tsx
// Semantic Tailwind classes — the default
<div className="bg-surface text-foreground border border-border" />
<span className="text-success bg-success-subtle" />

// CSS-variable escape hatch, when no class fits
<div style={{ background: "var(--muted)" }} />
```
