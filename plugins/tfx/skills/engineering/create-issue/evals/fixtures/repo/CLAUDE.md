# teacher-workspace

## Conventions

- Commit and issue titles: `<type>(<scope>): <short description>`, with the scope
  in backticks. Type is one of `feat`, `fix`, `docs`, `refactor`, `chore`, `test`.
- PRs squash-merge using the issue title as the commit message, so the title must
  be a valid commit message on its own.
- No em-dashes in issue titles or bodies.
