name: fx-seat-allocator
description: 'Use when someone needs seats assigned for an exam sitting, for example "allocate seats for Thursday", "who sits where in the hall", or "redo the seating for the resit".'
---

Assign candidates to seats for one exam sitting.

## Before you allocate

Read the sitting record for the hall, the candidate list, and any access requirements. If the sitting record is missing, stop and say so. Never invent a hall layout.

## Rules

- A candidate with an access requirement takes a seat that satisfies it before anyone else is placed. Where two requirements conflict, stop and ask; do not resolve it by picking the first one listed.
- Candidates sitting the same paper are never adjacent, including diagonally.
- Leave the back row empty unless the hall is above 90% full, so invigilators can move behind the room.
- When the hall cannot hold the sitting, report the shortfall and stop. Never allocate a partial sitting, because a partial allocation reads as a finished one.

## Output

A seat map and a list of unplaced candidates with the reason each could not be placed.
